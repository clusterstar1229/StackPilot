# StackPilot 实现设计

## 需求与组件

个人在 Windows 桌面管理数台 Linux 服务器，完成连接、部署、配置、资源查看和数据库操作。

| 组件 | 对应需求 |
|---|---|
| React 界面 | 简洁发布向导、专业工作台、文件和数据库操作 |
| Electron 主进程 | 凭据加密、文件选择、SSH 调用、构建任务与结果保存 |
| SSH/SFTP | 连接、终端、上传下载、隧道和远端操作 |
| 本机源码工作区 | Git 拉取、项目识别、构建命令和产物归档 |
| 本机 Docker | 编译项目并生成 Linux 运行镜像 |
| 远端 systemd / 容器 / Nginx | 应用运行、网站入口和版本切换 |
| 本地工作区文件 | 服务器资料、加密凭据、部署记录、指标和任务 |

## 数据流

成品包经检测和 SFTP 传到版本目录。主进程生成运行配置，启动服务并检查 HTTP，随后切换当前版本和保存记录。

源码从 Git 或本机目录进入构建工作区，经本机编译生成归档，再进入同一条 SSH 发布流程。配置和版本记录保留 Commit、镜像 ID 与 SHA-256。

## 交互与视觉

简洁模式使用概览和分步向导。专业模式使用资源表、YAML 检查器、日志、版本列表和交互终端。

默认窗口 1480×940，最小 1100×740。纸白 #FFFFFF、工作区 #F5F7FB、正文 #1D2A43、操作蓝 #3867F4、状态绿 #138A72。中文 Microsoft YaHei UI，代码 Cascadia Code / Consolas。

首次启动显示空工作区，演示工作区通过独立入口开启并显示标识。任务按检测、传输、配置、检查和发布呈现进度。

## 执行条件

SSH 主机指纹在首次连接时核对，凭据通过 Windows 系统加密。运行配置校验目录、端口和入口。图形变更显示目标与执行步骤，文件保存保留原副本。专业终端按操作者权限执行命令。

环境探测读取操作系统、包管理器、systemd、Nginx 和容器工具。所需权限、工具或配置缺失时，任务返回对应错误；发布失败按已保存版本恢复服务。

## 运行周期

远端应用由 systemd / 容器管理。证书续期和定时备份在服务器执行。本地资源采样、通知和交互会话随桌面运行。
