## 配置记录

Java 可设置独立 Java Home、逐行 JVM 参数、内存和 CPU。服务器连接可设置工具目录、容器 Socket 与客户端目录。

数据库安装创建独立容器和数据卷，设置内存、CPU 和进程数。关系型数据库恢复创建新库，SQLite 恢复创建新文件。容器升级先备份再复制数据卷，保留原实例。

PostgreSQL 流复制和 Redis 主从使用同主机节点。Redis 账号使用持久化 ACL，MongoDB 小内存实例通过私有 Socket 初始化。

应用备份目录为 `/var/backups/stackpilot/apps`，数据库备份目录为 `/var/backups/stackpilot/databases`。
