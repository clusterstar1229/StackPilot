# 栈桥 StackPilot 设计与实现约定

面向个人管理数台 Linux 主机。Windows 桌面本地运行，无远程管理后台、无公开本地 HTTP API；主进程通过 SSH/SFTP 操作服务器，渲染进程仅使用有类型且经过校验的 IPC。

## 视觉方向

- 纸白 #FFFFFF、工作区 #F5F7FB、海军蓝文字 #1D2A43、操作蓝 #3867F4、健康青 #138A72、注意琥珀 #C68719。
- 中文使用 Windows 本地 Microsoft YaHei UI，英文数字 Segoe UI，代码 Cascadia Code/Consolas。无联网字体依赖。
- 220px 导航栏、64px 顶栏、左对齐主工作区。概览以服务器列表、可追踪任务和曲线为主，避免所有信息都堆成同形卡片。统一 8px 间距体系。
- 最有辨识度的元素是应用部署的阶段轨迹：检测、传输、配置、检查、发布、回滚。其余区域保持安静。
- 初次启动无虚假在线服务器；演示工作区须主动开启，始终显示演示标识，不能调用主进程写操作。

```
导航栏 | 工作区 / 当前模块                     模式切换  快速部署
       | 标题、环境状态                          主要操作
       | 关键数据与趋势          | 待办 / 风险 / 任务
       | 服务器或应用列表（筛选、状态、明确的操作入口）
```

对初始方案的复核：移除常见的巨幅渐变欢迎区、重复 KPI 阴影卡片和无意义技术标签。以真实运维对象和操作结果为内容，新手模式显示解释，专业模式增加配置、服务和诊断入口。

## 操作权限

禁止应用内服务器重启/关机、删除数据库/数据卷、任意 Shell 执行和破坏性 SQL。中危操作使用主进程生成的一次性计划，显示目标、步骤、影响和指纹；用户确认后提交，不能通过传入 confirmed=true 绕过。基础安装和发布流程自动化；防火墙、DNS、证书、安全配置及接管服务变更需确认。上传的程序及 Compose 是用户信任的可执行内容。

## 兼容策略

通过 /etc/os-release、包管理器、systemd、Nginx include、Docker 能力探测，分别启用 apt/dnf/yum 适配。发行版停止维护或仓库不可用时显示原始错误，不宣称所有历史发行版均已验证。已有服务先发现再接管，不覆盖未知配置。

## 监控与任务

桌面运行时采样，保留最多 7 天数据。关闭应用不再采样；服务器 systemd/容器、ACME 续期和备份 cron 持续运行。数据库远程连接优先通过 SSH 隧道。没有连接时任何远端数据均显示为空。
